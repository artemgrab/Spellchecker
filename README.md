# Контекстна перевірка правопису 📝

Високопродуктивний десктопний застосунок для перевірки орфографії та граматики з урахуванням контексту, створений за допомогою **C++** та **Qt Framework**. 

На відміну від стандартних систем, які лише звіряють слова з плоским словником, цей застосунок використовує комбінацію **префіксних дерев (Trie)**, **динамічного програмування (відстань Левенштейна)** та **статистичного мовного моделювання (біграми)** для надання найбільш логічних та точних підказок.

✨ Основні можливості

* **Розширена токенізація тексту:** Використовує `QRegularExpression` для надійного вилучення слів, ігноруючи пунктуацію та цифри.
* **Контекстні підказки:** Ранжує варіанти виправлення на основі частоти спільного вживання сусідніх слів за допомогою хеш-таблиці біграм, що гарантує граматично логічні пропозиції.
* **Базова перевірка граматики:** Автоматично виявляє дублювання слів (наприклад, "пішов до до лісу") та помилки регістру після розділових знаків.
* **Високопродуктивний пошук:** Реалізує пошук у глибину (DFS) по структурі Trie з динамічним відсіканням гілок (Pruning) для генерації підказок за мілісекунди.
* **Інтерактивний UI:** Кастомні контекстні меню (`QMenu`), що викликаються кліком по слову, з візуальним виділенням помилок (`QTextCharFormat::SpellCheckUnderline`).
* **Збереження форматування:** Розумна логіка капіталізації гарантує: якщо помилка сталася на початку речення, підказка автоматично почнеться з великої літери.

## 🧠 Під капотом (Алгоритми та структури даних)

Цей проєкт значною мірою спирається на оптимізовані алгоритмічні рішення для обробки великих текстів у реальному часі:

1. **Словник на базі Trie (Префіксне дерево):** Слова завантажуються в оптимізоване по пам'яті дерево. Це зменшує часову складність пошуку до $O(L)$ (де $L$ — довжина слова), роблячи швидкість незалежною від розміру словника.
2. **Відстань Левенштейна (Динамічне програмування):**
   Обчислює мінімальну кількість односимвольних операцій (вставок, видалень або замін), необхідних для перетворення одного слова на інше.
3. **DFS з евристичним відсіканням гілок:**
   Замість розрахунку відстані Левенштейна для всього словника, алгоритм обходить Trie і вираховує відстань динамічно для префіксів. Якщо відстань перевищує допустимий ліміт (1-2 помилки залежно від довжини слова), уся гілка миттєво відкидається.
4. **Каскадне сортування (Багатофакторне ранжування):**
   Підказки сортуються за допомогою лямбда-функції С++, яка оцінює кандидатів за трьома критеріями:
   - Найменша відстань Левенштейна (Орфографія).
   - Найвища частота біграм (Статистичний контекст).
   - Найкоротша довжина слова (Тай-брейкер).

## 🛠️ Технологічний стек

* **Фреймворк:** Qt 6 (QtWidgets, QtGui, QtCore).
* **Структури даних:** `QHash`, `QVector`, `Trie`.
